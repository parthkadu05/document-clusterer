Project Title 
Document Clustering System 

1. Introduction 
In today’s digital environment, the main challenge for a single user is not just storing documents, but finding the right document quickly when needed. Users often save PDFs, notes, reports, research papers, screenshots, and text files in different folders, which creates confusion over time. 
This project focuses on designing a user-centered prototype solution that helps an individual automatically organize their personal and academic documents. Instead of thinking from a system-only perspective, the prototype is built around how the user searches, thinks, stores, and retrieves files. 
The solution uses AI-based hierarchical clustering to create a tree-like organization structure that matches the user’s mental model, making navigation easier and reducing frustration. 

2. Problem Statement 
Large collections of textual documents are difficult to organize, search, and analyze manually.  
Traditional flat clustering methods fail to show relationships between document groups and do not provide multi-level categorization. 

3. Objectives 
To improve user productivity and workflow 
To reduce manual effort in document classification 
To reduce the user’s time spent searching files 
To minimize manual folder creation and sortin 

4.Challenge Statement
The user currently saves documents quickly during study or work without following any meaningful structure, which later makes retrieval difficult and time-consuming. 
The user remembers the content or topic of the file but not the exact file name or folder path, causing repeated search loops across multiple folders and interrupting the workflow
